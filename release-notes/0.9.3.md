The greeting no longer draws while Windows is still signing you in.

**Install** (open PowerShell and paste this):

```powershell
irm https://raw.githubusercontent.com/hafizuddin-a/bismillah-startup/main/get.ps1 | iex
```

No admin rights needed. If you already have Bismillah, it will offer this update itself (**Check for Updates…** in the tray menu).

**What changed**
- **Lock screen:** Windows 10 and 11 show the lock screen as a picture first, and only show the password or PIN box after a key press, so the app didn't know it was locked (a fingerprint can skip the box entirely). It now recognises the lock screen picture itself, as well as the password and PIN screen, and waits until you are signed in before writing the bismillah.
- **Waits for the desktop:** it also waits until the taskbar is back, and while the Start menu or search is open, so the popup isn't half hidden behind them. (Windows always draws the Start menu above ordinary windows, so the popup can't be placed over it.)
- **Launch at Login:** waits a little longer after sign-in, while Windows is busy.
- The log (`%APPDATA%\Bismillah\bismillah.log`) now says what the app was waiting for and why.
