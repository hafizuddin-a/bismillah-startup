The dhikr text now looks the same as on the Mac.

**Install** (open PowerShell and paste this):

```powershell
irm https://raw.githubusercontent.com/hafizuddin-a/bismillah-startup/main/get.ps1 | iex
```

No admin rights needed. If you already have Bismillah 0.9.0, it will offer this update itself (**Check for Updates…** in the tray menu).

**What changed**
- The dhikr Arabic is drawn with the same letter shapes as the Mac app instead of the Windows system font, so it no longer looks thin or different.
- While the dhikr shape is still opening, the text stays inside it instead of showing outside the edges.
- Build pipeline updated to current GitHub Actions versions.

See the [README](https://github.com/hafizuddin-a/bismillah-startup#readme).
