Faster to appear after you sign in.

**Install** (open PowerShell and paste this):

```powershell
irm https://raw.githubusercontent.com/hafizuddin-a/bismillah-startup/main/get.ps1 | iex
```

No admin rights needed. If you already have Bismillah, it will offer this update itself (**Check for Updates…** in the tray menu).

**What changed**
- **Quicker greeting at sign-in:** the app no longer waits an extra 10 seconds after Windows starts it. It still waits if the lock screen, a loading desktop or the Start menu is in the way.
- **Quicker start:** the app file is no longer compressed, so it doesn't have to unpack itself into memory on every launch. The download is about the same size; the installed file is larger.
- The log (`%APPDATA%\Bismillah\bismillah.log`) now records how long the PC had been on when the app started and how long after that the greeting appeared, so a slow start can be traced.

**About the rest of the delay:** Windows 11 itself holds back sign-in apps until the PC has gone quiet, about 10 seconds, and longer with many startup apps. Bismillah can't change that.
