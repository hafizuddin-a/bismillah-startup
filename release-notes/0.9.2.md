Fixes from the first real-PC test.

**Install** (open PowerShell and paste this):

```powershell
irm https://raw.githubusercontent.com/hafizuddin-a/bismillah-startup/main/get.ps1 | iex
```

No admin rights needed. If you already have Bismillah, it will offer this update itself (**Check for Updates…** in the tray menu).

**What changed**
- **The menu stays open** while you change settings (dhikr count, start and end hours, Launch at Login, Show on All Screens, Update Automatically). The ticks update as you click. It closes for actions such as Show Bismillah and Quit.
- **Waking from sleep or closing the lid:** the bismillah now waits for you to sign in (password, PIN or fingerprint) and then writes itself out, instead of playing behind the lock screen.
- **Launch at Login:** starting at sign-in is now more careful. The app waits for the desktop to be ready before greeting, no longer stops if Windows is still setting up, and writes what happened to `%APPDATA%\Bismillah\bismillah.log` so a problem can be traced.

See the [README](https://github.com/hafizuddin-a/bismillah-startup#readme).
